🤖 Android — installer wairyu

✅ RECOMMANDÉ — jamais bloqué par Play Protect

Installe wairyu via Chrome : l'application créée est signée par Google — Play Protect ne peut pas la bloquer. Même plein écran, même notifications, aucun avertissement.

📲 Installer maintenant
  1. Ouvre wairyu.wairyu.workers.dev dans Chrome.
  2. Appuie sur 📲 Installer (ou menu ⋮ → « Installer l'application » ou « Ajouter à l'écran d'accueil »).
  3. Confirme Installer — l'icône wairyu apparaît sur l'écran d'accueil.
  4. Ouvre wairyu depuis cette icône : plein écran, notifications actives.
Option — APK direct (Play Protect peut le signaler) 📥 Télécharger l'application Version 1.0.0 · 1,4 Mo · installation directe
  1. Télécharge l'APK avec le bouton ci-dessus.
  2. Ouvre le fichier téléchargé ; Chrome peut demander d'autoriser l'installation de cette source → « Autoriser ».
  3. Appuie sur Installer, puis ouvre wairyu — elle se comporte comme une vraie app (plein écran, notifications).
🛡️ « App bloquée » par Google Play Protect pendant l'installation de l'APK ? C'est le comportement normal pour toute app hors Play Store — pas un virus. Sur l'écran de blocage : appuie sur « Plus de détails », puis « Installer quand même ».
🛡️ wairyu déjà installée mais désactivée / supprimée par Play Protect ? Ouvre le Play Store → icône de profil → Play Protect → rouvre le rapport, touche wairyu, puis « Autoriser » (ou désactive temporairement l'analyse). Sinon : Réglages Android → Applications → wairyu → Activer.
👉 L'installation via Chrome ci-dessus évite tout cela pour toujours — et les notifications reviennent dès que l'app n'est plus bloquée.
L'app est la version officielle de wairyu.wairyu.workers.dev, signée et vérifiée par Android. Aucun store intermédiaire, aucune donnée revendue — le 100 % gratuit reste total.
Le téléchargement ne démarre pas ? Tu es peut-être dans un navigateur intégré (WhatsApp, Facebook) : appuie sur ⋮ puis « Ouvrir dans Chrome », ou copie ce lien dans Chrome : wairyu.wairyu.workers.dev/app

🍎 iPhone / iPad — installation PWA

iOS n'autorise pas les APK : wairyu s'installe directement depuis Safari, en 4 gestes.

  1. Ouvre wairyu.wairyu.workers.dev dans Safari et connecte-toi.
  2. Appuie sur le bouton Partager (carré avec flèche ↑).
  3. Choisis « Sur l'écran d'accueil ».
  4. Appuie sur Ajouter — l'icône wairyu apparaît, l'app s'ouvre en plein écran.
Sur iPhone, c'est AUSSI l'étape obligatoire pour recevoir les notifications (exigence iOS 16.4+). Sur Android installé via l'APK, les notifications sont actives dès l'ouverture.

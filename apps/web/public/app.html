📥 Télécharger l'application Version 1.0.0 · 1,4 Mo · installation directe
  1. Télécharge l'APK avec le bouton ci-dessus.
  2. Ouvre le fichier téléchargé ; Chrome peut demander d'autoriser l'installation de cette source → « Autoriser ».

🍎 iPhone / iPad — installation PWA

iOS n'autorise pas les APK : wairyu s'installe directement depuis Safari, en 4 gestes.

  1. Ouvre wairyu.wairyu.workers.dev dans Safari et connecte-toi.
  2. Appuie sur le bouton Partager (carré avec flèche ↑).
  3. Choisis « Sur l'écran d'accueil ».
  4. Appuie sur Ajouter — l'icône wairyu apparaît, l'app s'ouvre en plein écran.
Sur iPhone, c'est AUSSI l'étape obligatoire pour recevoir les notifications (exigence iOS 16.4+). Sur Android installé via l'APK, les notifications sont actives dès l'ouverture.

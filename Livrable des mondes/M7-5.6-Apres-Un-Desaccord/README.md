*Ce qui se passe après* — s'excuser, faire le premier pas, désamorcer, tourner la page,
recevoir l'excuse : les cinq gestes qui décident si un désaccord reste banal.

## Les 5 capacités — noms génériques UI

**savoir s'excuser · faire le premier pas · utiliser l'humour pour désamorcer ·
tourner la page sans ruminer · accepter l'excuse de l'autre.**
Le concept de **réparation** est public (recherche conjugale) ; le nom d'auteur associé
reste **hors rendu**. Les items sont 100 % originaux Wairyu. Aucune capacité n'est jugée :
la réparation se mesure à **ce qui se passe après** le désaccord — pas à la fréquence des
disputes. Le niveau se travaille : le miroir ouvre une porte, il ne scelle rien.

## Point d'architecture — le modulateur [MOTEUR SEUL]

**Jamais au rendu** : le croisement réparation (5.6) × posture dans le conflit (5.4) —
réparation élevée × conflit vif = couple viable (l'amplificateur documenté au refonte) ;
réparation basse × conflit évitant = le mur de silence qui s'installe. Le rendu ne connaît
pas ce croisement : la sortie de quête raconte un muscle entraînable, jamais un verdict
(gravé au 00-README, 03, 04, 06).

# Dossier `etapes/` — Livrables par étape

Ce dossier reçoit, au fur et à mesure de leur **achèvement intégral**, les livrables de chaque étape du plan de réalisation :

- le compte-rendu de l'étape (décisions prises, écarts éventuels avec le plan) ;
- les artefacts produits (code source par étape quand applicable, documents, jeux de données, checklists de validation) ;
- la preuve de validation de la porte (*gate*) de l'étape.

Convention de nommage :

```
etapes/
├── etape-00-cadrage/
├── etape-01-socle-technique/
├── etape-02-authentification/
├── etape-03-profils-photos/
├── etape-04-questionnaire-matching/
├── etape-05-decouverte-dual-mode/
├── etape-06-chat-revelation/
├── etape-07-securite-moderation/
├── etape-08-monetisation-preperee/
├── etape-09-qualite-tests-beta/
├── etape-10-lancement-francophonie/
└── etape-11-post-lancement-scale/
```

Le tableau de bord global se trouve dans [`STATUS.md`](../STATUS.md) — il est mis à jour à chaque livraison.

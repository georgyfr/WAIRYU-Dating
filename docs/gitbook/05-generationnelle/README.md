# Dimension Générationnelle — la dimension et ses arbitrages

> La première extension du programme (RIO-16 → RIO-18) : le temps, la
> légitimité, la conversation de l'horizon. Ancre canon (ligne 112) :
> « Les horloges (Carstensen), la taxe de légitimité, la conversation de
> l'horizon ». Séquence tronquée à 3 quêtes par arbitrage fondateur A2 :
> **carte → croisement → pas**.

## Les trois axes (mapping 1:1)

| Axe | Nom | Faces |
|---|---|---|
| **H** | L'horloge | H1 horizon perçu · H2 priorisation |
| **L** | La légitimité | L1 taxe de justification · L2 permission à deux |
| **C** | La conversation de l'horizon | C1 ouverture · C2 évitement |

**Palier = max(niveau H, L, C)**, zéro exception.

- **Q2-A4** : L6 verbatim (percentiles, population ≥ 2 000, seed 42, boucle

## Ce que cette dimension hérite et transmet

- Les couches **L1-L7** (RQS, scores/CI90, niveaux, hiérarchie, empreinte,
  styles, RCI) sont reprises de l'attachement avec les paramètres propres à
  l'échelle 1-4 (SEM 0,2517, CI90 ± 0,4128, seuil de hiérarchie 0,8937).
- Les bornes de traversée du RCI (Q3) : axe H → bornes croisement
  **2,50/3,50** (héritées de Q2) ; axes L/C → seuils L3 **1,80/2,60/3,20**
  (RIO-16). Une mesure, un rôle.
- **Anti-collision des registres publiés** (Q3) : vérification explicite
  contre RIO-05 (6 pas), RIO-15 (7 pas), RIO-17 (9 configs + 3 inférences)
  — aucun nom ni mécanisme dupliqué.
- La population percentile est **héritée de Q2, jamais recalculée** (Q3).

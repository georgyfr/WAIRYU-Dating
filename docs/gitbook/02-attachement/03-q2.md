# RIO-02 — Q2 « Ce qui m'effraie vraiment » (WTC-Q2-R1)

> L'empreinte des peurs : déclencheurs cochés, comportements de proteste,
> filet de sécurité H5. Références citées : Mikulincer & Shaver
> (hyperactivation/déactivation), Bowlby (proteste).

## Les entrées (pas de Likert ici — format hétérogène)

| Bloc | Items | Format |
|---|---|---|
| Déclencheurs distance | D1-D6 | cochés 0/1 |
| Déclencheurs proximité | P1-P4 | cochés 0/1 |
| Comportements H | H1-H5 | fréquence 0-3 (**H5 = comportement de sécurité**) |
| Comportements R | R1-R3 | fréquence 0-3 |
| Alarme intérieure | `i_alarm` | entier 0-10 |
| Héritage Q1 | `sA`, `sB` | scores d'axes |

## L'algorithme en 8 étapes

### 1. Profil de déclencheurs
`cd` = déclencheurs distance cochés, `cp` = proximité cochés.

```
cd + cp ≤ 2                      → RARES
cd ≥ 3 et cp ≥ 2                 → DEUX_CÔTÉS
cd − cp ≥ 2                      → DISTANCE
cp ≥ 2 et cd ≤ 2                 → PROXIMITÉ
sinon                            → MIXTE_LÉGERS
```

### 2. Comportements
`h_norm = ΣH/15`, `r_norm = ΣR/9` (3 décimales).

```
|hn − rn| < 0,20 et hn ≥ 0,30 et rn ≥ 0,30  → MIXTE
hn − rn ≥ 0,20                               → H (hyperactivation)
rn − hn ≥ 0,20                               → R (déactivation)
sinon                                        → LÉGER
```

### 3. Filet de sécurité H5 (la voie qui deviendra D-CRISE)
```
signal  : h5_freq ≥ 1 ET (score_A ≥ 3,21 OU i_alarm ≥ 7)
p_filtre: h5_freq = 3 ET score_A ≥ 3,70
```

### 4. Convergence Q1 × Q2
```
C1 : si sA ≥ 2,61 → cd ≥ 2 attendu
C2 : si sB ≥ 2,61 → cp ≥ 1 ou rn > hn attendu
C3 : si sA < 2,61 et sB < 2,61 → cd+cp ≤ 2 et ≤ 1 coché attendu
index = satisfaits ÷ applicables → prudence si ≤ 0,50 ; supprime l'OMBRE si 0,00
```

### 5. Nommage (priorité : LES DEUX > PEUR simple > ZONE CALME)
```
les_deux : (sA ≥ 2,61 et sB ≥ 2,61) OU (cd ≥ 3 et cp ≥ 2)
           OU (hn ≥ 0,30 et rn ≥ 0,30 et |hn−rn| < 0,20)
p_perdre : (sA ≥ 2,61 OU cd ≥ 3) ET domination = H
p_étouff : (sB ≥ 2,61 OU cp ≥ 2) ET domination ∈ {R, MIXTE}
z_calme  : Q1 Tranquille ET cd+cp ≤ 2 ET ≤ 1 coché ET i_alarm ≤ 4
repli    : i_alarm ≥ 5 → ALARME SANS MAIN, sinon SIGNAL LÉGER NON NOMMé (D-Q2-1)
```

### 6. zone_force
SÉCURISANT (origine O1) / CALME_RICHE / LUCIDITÉ (LES DEUX) /
MAINS LIBRES (profil ≠ RARES et hn+rn < 0,30) / sinon **SILENCIEUSE**.

### 7. Palier
```
🔴 : signal sécurité OU i_alarm ≥ 8 OU sA ≥ 3,70 OU (sA ≥ 3,21 ET sB ≥ 3,21)
🟠 : i_alarm ≥ 6 OU 0,30 ≤ hn+rn < 0,60
🟢 : sinon
```

### 8. Longitudinal
Seuils de re-test : `i_alarm ± 2`, normes ± 0,15 — **non testé au package**
(décision D-Q2-F, reporté à WTC-SUIVI).

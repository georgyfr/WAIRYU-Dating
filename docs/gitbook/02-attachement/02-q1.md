# RIO-01 — Q1 « Comment je me raccroche » (WTC-Q1-R1)

> Instrument fondateur : 18 items, 2 axes indépendants, 6 faces. Le package
> initial a rendu **À CORRIGER (9/10)** ; la révision **R1** a recalibré la
> structure d'erreur et re-testé — c'est la version de référence.

## L'algorithme en 7 couches

### Couche 1 — RQS : le filtre de qualité de réponse

Le score RQS démarre à 100 et reçoit quatre pénalités :

| Contrôle | Condition de pénalité | Pénalité |
|---|---|---|
| Anti-linéarité | écart-type des 18 items corrigés (ddof=1) **< 0,45** | −20 |
| Anti-contradiction | pour chaque item inversé (5, 15) : \|corrigé − moyenne des 2 autres items de sa face\| **≥ 2,5** | −20 (une seule fois au total) |
| Rythme | ≥ **5** items répondus en **< 2,0 s** OU session **< 60 s** | −25 |
| Vigilance | la 19ᵉ question ≠ **3** | −20 |

Statuts : **OK ≥ 85 · PRUDENCE 70-84 · INVALIDE < 70**. « Piégé » ⇔ statut ≠ OK.

### Couche 2 — Scores et intervalles

- `face = moyenne des 3 items` ; `axe = moyenne des 9 items` (arrondis à 2
  décimales **avant** tout passage de seuil).
- **R1 : SEM_AXE = 0,195** (structure d'erreur recalibrée ; le run initial
  utilisait un placeholder 0,65×√(1−0,85) ≈ 0,25175).
- **CI90 = score ± 1,64 × 0,195 = ± 0,3198** (Z90 = 1,64).

### Couche 3 — Lecture à quatre niveaux (par axe)

```
Discrète  < 1,80
Tranquille < 2,60
Vive      < 3,20
Forte     ≥ 3,20
```

**Règle conservatrice** : si le CI90 chevauche un seuil, la lecture devient
« FRONTIÈRE — entre X et Y » et la **décision conservatrice** est le **niveau
le plus bas touché**.

### Couche 4 — Hiérarchie de faces

Une face n'est déclarée dominante que si son avance dépasse l'incertitude
combinée des deux SE :

```
écart ≥ 1,64 × √(SE_face1² + SE_face2²)  avec SE_face = 0,72×√(1−0,72) ≈ 0,38105
→ seuil ≈ 0,8836
```

(Divergence documentée : un commentaire du code écrit « ≈ 0,8837 », le
rapport et la formule donnent **0,8836** — l'écart est éditorial, voir partie VII.)

### Couche 7 — Changement fiable (re-test 8 semaines)

Version R1 : `SE_diff = √2 × 0,195 ≈ 0,27577` ; **FIABLE si |Δ| ≥ 0,45227**
(= 1,64 × SE_diff) ; **SUGGESTION si ≥ 0,41** ; sinon **BRUIT**.
(Le run initial donnait 0,58381 — la révision R1 a resserré le seuil sur la
structure d'erreur recalibrée.)

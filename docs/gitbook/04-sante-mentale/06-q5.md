## Le RCI (L7 — re-test à 8 semaines, A4)

Constante gravée : `SE_DIFF = 0,356` (« √2 × SEM ≈ 0,356 »). Le simulateur
en déduit `SEM_L7 = 0,356/√2 ≈ 0,252` pour bruiter le re-test. Δ = re-test
− base (**asymétrie temporelle sans exception** — testée : 150/150
inversions exactes).

```

|Δ| ≥ 0,41 → SUGGESTION
sinon      → BRUIT
```

**Agrégation d'ensemble = max des statuts** (BRUIT < SUGGESTION < FIABLE) →
libellés « UN CHANGEMENT FIABLE » · « UNE PISTE À CONFIRMER » · « DANS LE
BRUIT DE LA MESURE ».

**Signification clinique** : traversée des bornes A1 2,50/3,50 —
`traverse_borne_de : niveau_de(base) != niveau_de(re_test)` (ex. « ÉLEVÉ →
MOYEN »). Une mesure, un rôle : les mêmes bornes que le croisement Q4.

# PARTIE 1 — LE PROJET ET SON OBJECTIF

## 1.1 La définition du projet

WAIRYU Thérapie Couple (WTC) est une application d'accompagnement relationnel
destinée aux personnes qui estiment avoir des difficultés dans leur couple. Son
objectif n'est ni de complimenter ni de condamner : c'est de déceler les
mécanismes qui alimentent les tensions, dimension par dimension, et de proposer
des mesures de correction graduées — jusqu'à l'orientation professionnelle quand
nécessaire.

## 1.2 Les principes fondateurs

- Honnêteté sans condamnation : l'app cherche les tensions avérées, jamais elle
  ne fabrique de pathologies ni ne flatter ;
- Ombre ET lumière structurelles : chaque résultat contient les deux — tirés des
  vraies réponses, jamais fabriqués ;
- Jamais le mot « pathologie » à l'écran : on dit « zones d'ombre », « zones de
  vulnérabilité » ;
- Langage simple : compréhensible sans études supérieures (phrases ≤ 15 mots,
  mots du quotidien) ;
- Descriptif → conséquence → possibilité : jamais d'adjectif de valeur dans un
  sens comme dans l'autre ;
- Jamais l'évaluation du partenaire ni des tiers : tout est auto-déclaration ;
- Le filet de sécurité : détection du contrôle coercitif, des violences, de
  l'idéation suicidaire → orientation vers les ressources (3919, 3114) —
  priorité absolue ;
- Instruments 100 % originaux : construits scientifiques publics cités,
  instruments créés ex nihilo, zéro copie d'outils payants ou sous autorisation ;
- Inclusivité par conception : « partenaire 1 / partenaire 2 », aucune
  présupposition ;
- L'app se retire : quand le couple se rencontre, Solène s'efface — la métrique
  de succès est le changement vérifié, pas la rétention.

## 1.3 Le positionnement concurrentiel

- Face aux apps conversationnelles (Lovon, Kana) : profondeur clinique + mesure
  validée + filet de sécurité + institutions de couple — avec leur force reprise
  (l'entrée conversationnelle sans friction) ;
- Face aux téléthérapies humaines (Regain, Unobravo, Cope House) : la couche
  d'entre-deux-séances qu'aucune ne fournit — le travail structuré, mesuré, le
  mode thérapeute (B2B2C) ;
- La métrique différenciante : le changement prouvé (RCI, deltas fiables) —
  personne sur le marché ne le montre.

## 1.5 Le persona Solène — la règle capitale

Solène est la guide de l'app. Elle parle comme un thérapeute mais se présente
comme ce qu'elle est : un guide conçu avec des thérapeutes, qui ne remplace
personne. Architecture en 3 phases :

- Phase 0 (lancement) : moteur déterministe — zéro IA générative, textes 100 %
  validés, calcul local ;
- Phase 1 : IA émotionnelle par API (candidats : Claude, GPT-4o, GLM lui-même —
  arbitrage par test à l'aveugle) avec filtre de sortie ;
- Phase 2 : fine-tuning open-weight (Llama/Mistral) sur notre corpus — l'actif
  propriétaire.

Routage : calculs → déterministe ; écoute libre → IA émotionnelle ; écrans
critiques et sécurité → mots validés JAMAIS l'IA ; filtre de sortie sur tout.

# PARTIE 5 — LES 110 QUÊTES : LE STANDARD

## 5.1 Le gabarit universel

```
QUÊTE [n°] — [titre simple]
POURQUOI CETTE QUÊTE (1 phrase) · CE QUE TU VAS FAIRE (durée/format)
CE QUE TU APPRENDRAS
ACTIVITÉ (questions/exercice/journal)
RÉSULTAT : « CE QU'ON VOIT DANS TES RÉPONSES »
  → ta zone d'ombre [descriptif causal, sans étiquette]
  → ta zone de force [tirée des vraies réponses]
CE QUE TU PEUX CHANGER (3 paliers)
QUAND DEMANDER DE L'AIDE (seuils)
```

## 5.2 Les 4 filtres de chaque question

1. Mesure quelque chose d'observable ;
2. Pas de « bonne réponse » sociale ;
3. Niveau collège ;
4. Reliée à un construit scientifique cité.

## 5.3 La structure 5 quêtes par dimension majeure

Q1 La carte (mesure) · Q2 L'ombre (mécanisme profond) · Q3 La lumière (forces
dérivées) · Q4 Le croisement (à deux, confirmé) · Q5 Le pas (1 changement +
suivi 14 jours). Extensions : 3 quêtes. Total ≈ 110.

## 5.4 Les 3 paliers des suggestions

🟢 Seul(e) (ombre légère → exercice maison) · 🟠 À deux (moyenne → module de
couple) · 🔴 Professionnel (élevée/signal → orientation chaleureuse, « le
chemin le plus court, pas un échec »).

## 5.5 La règle anti-fabrication

Zone calme = résultat affiché comme tel (« cette zone est calme chez toi —
rien à fabriquer ») ; force silencieuse = dit sans invention (« terrain de
travail, pas un verdict »).

## 5.6 La répartition des quêtes (26 dimensions, ≈ 110 quêtes)

Tableau complet avec noms — déjà fourni dans la réponse « organisation en
quêtes », récapitulé : 5 quêtes pour 16 dimensions majeures, 4 pour 6
dimensions, 3 pour 4 extensions.

# PARTIE 6 — LES MÉCANISMES DE CALCUL DÉTAILLÉS

## 6.1 Quête 1 « Comment je me raccroche » — le standard de référence

Instrument original (fiche RIO-01) : 18 items (2 axes × 3 faces × 3 items),
échelle 1-4, 2 items inversés (5, 15), 1 item de vigilance. Construit cité :
attachement adulte (Bowlby ; Brennan, Clark & Shaver).

Les 8 couches de calcul :

| Couche | Contenu |
|---|---|
| L1 RQS | Qualité de réponse 0-100 : anti-linéarité (SD < 0,45 → pén. 20), anti-contradiction (inversés vs frères, écart ≥ 2,5 → pén. 20), rythme (< 2 s/item sur ≥ 5 ou session < 60 s → pén. 25), vigilance (pén. 20). Seuils : ≥ 85 OK · 70-84 PRUDENCE · < 70 INVALIDE (aucun résultat) |
| L2 | Scores faces (3 items) + axes (9 items), moyenne 1,00-4,00 · intervalle 90 % = score ± 1,64 × SEM · SEM = SD_pop × √(1−α) — placeholders (SD 0,65, α 0,85) à remplacer par le pilote |
| L3 | Lecture 4 niveaux (Discrète < 1,80 ≤ Tranquille < 2,60 ≤ Vive < 3,20 ≤ Forte) · si intervalle chevauche un seuil → FRONTIÈRE nommée + décision conservatrice (niveau bas) |
| L4 | Faces dominantes : hiérarchie affichée seulement si écart ≥ 1,64 × √(SE_f1² + SE_f2²) — sinon « nuage » (anti-surinterprétation) |
| L5 | Empreinte situationnelle (croisement Q1×Q2) + 3 inférences non-évidentes (alarme intérieure, mains libres, le près coûte) |
| L6 | Couple par PERCENTILES (correction du style de réponse) · boucle probable si écart de percentiles ≥ 30 · avertissement si styles dissemblables |
| L7 | RCI longitudinal (Jacobson & Truax) : SE_diff = √2 × SEM ≈ 0,356 · \|Δ\| ≥ 0,58 = FIABLE · 0,41-0,58 = SUGGESTION · < 0,41 = BRUIT · + signification clinique si seuil traversé |
| L8 | Assemblage des 7 blocs (position · forme · empreinte · couple · force · limites · palier/pas) + flux vers Q2-Q5 |

Puissance : < 1 000 opérations, < 1 ms, 100 % local — zéro envoi de données.

Les 12 configurations individuelles de sortie : 4 d'axe simple (Discrète /
Vive-Forte × chaque axe) · mixte · tranquille · 5 frontières · 2 cas de
qualité — chacune avec ombre ET force affichées.

Objectifs mesurables : RQS ≥ 85 pour ≥ 80 % des utilisateurs · effet de
reconnaissance ≥ 70 % (« ça te ressemble ? ») · routage sécurité 100 % ·
re-test programmé à 8 semaines.

## 6.2 Quête 2 « Ce qui m'effraie vraiment » — formats mixtes

- Étape 1 : 10 déclencheurs (6 distance D1-D6, 4 proximité P1-P4) + I_alarm
  (0-10) → profils dominants ;
- Étape 2 : 8 comportements × fréquence (1-3) → Score_H_norm (÷15),
  Score_R_norm (÷9), domination (écart ≥ 0,20), H5 (téléphone) = routage
  sécurité ;
- Étape 3 : origine (7 choix guidés + texte libre → NLP local, confiance
  ≥ 0,70 sinon NON-CLASSIFIABLE) : SÉCURISANT, INVALIDATION, INVISIBILITÉ,
  PARENTIFICATION, INTRUSION, MIXTE ;
- Index de convergence Q1×Q2 (C1-C3) : 1,00 normal · 0,50 prudence · 0,00 pas
  de nommage ;
- Nommage (arbre) : LES DEUX > PEUR DE PERDRE > PEUR D'ÊTRE ÉTOUFFÉE > ZONE
  CALME — le comportement tranche les ambigus ;
- Récit causal : templates origine × comportement × conséquence +
  phrase-pivot constante (« elle t'a protégé(e) là où tu as grandi... ») ;
- Paliers : 🟢 I_alarm ≤ 5 et mécanismes légers · 🟠 6-7 ou boucle · 🔴 ≥ 8 ou
  A ≥ 3,70 ou signal sécurité.

## 6.3 Les standards des autres quêtes (mêmes principes)

Q3 (forces dérivées, jamais fabriquées — le défi du positif) · Q4 (croisement
à 9 configurations, percentiles) · Q5 (tracking 14 jours, seuils
anti-perfectionnisme : 9/14 = célébré, jamais de sanction).

## 6.4 La chaîne de traçabilité

Chaque chiffre remonte à ses items → ses construits → ses blocs d'écran. Zéro
chiffre sans source. Les 7 blocs du résultat couvrent toute la quête
(position, forme, empreinte, couple, force, limites, pas).

## 6.5 Le protocole de validation approfondi

Pilote N=150-200 (α, SD, item-total ≥ 0,30, structure factorielle) ·
stabilité test-retest 2 semaines (≥ 0,80) · normes (percentiles) · paramètres
réels (SEM, RCI) · recalibrage continu à chaque 500 sessions.

# PARTIE 8 — LA STRATÉGIE D'INSTRUMENTS ORIGINAUX (RIO)

- Doctrine : construits scientifiques publics (cités), instruments 100 % ex
  nihilo, outils libres utilisés tels quels (PHQ-9, GAD-7, PCL-5, ACE, EPDS,
  AUDIT, SCOFF, ASRS, K6, PC-PTSD-5), zéro outil payant/sous autorisation,
  zéro reformulation-proche ;
- Processus 7 étapes : construit → dimensions maison → rédaction ex nihilo
  (langage simple, situations couple) → scoring maison → validation pilote →
  documentation → vérification d'originalité ;
- Le Registre des instruments originaux (RIO) : fiche type (nom maison,
  construit cité, items, architecture, scoring, validation, originalité
  vérifiée) — ~40-50 instruments prévus ;
- 3 terrains de supériorité : langage (situations réelles de couple),
  auditabilité (RQS, convergence, fiabilité par session), longitudinal intégré
  (RCI) ;
- Contre-indications absolues : jamais cloner (ECR, YSQ, DAS, KMSI, Willcox,
  Duluth graphique, Chapman, Gottman matériaux, EFT/Hold Me Tight, CTS2,
  MBI...) ;
- Vocabulaire écran : jamais « pathologie / diagnostic / dépistage » —
  « tendances, configurations, pistes avec un professionnel ».

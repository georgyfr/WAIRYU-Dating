## 2. Architecture : 1 pas + suivi 14 jours + re-test 8 semaines

**Trois couches, une seule mécanique de classement** :

1. **Le pas** — UN changement, choisi par le couple (source : A2, §9). Champ tracé : intitulé du pas · palier de suggestion (🟢🟠🔴) · jour de départ.
2. **Le suivi 14 jours** — check-in quotidien (mécanique : A1, §9) ; statut d'engagement = jours tentés / 14. **Seuil anti-perfectionnisme verbatim ligne 297-298 : 9/14 = célébré, jamais de sanction** — atteindre 9, 10 … 14 est célébré ; passer sous 9 reste un constat d'engagement avec relance chaleureuse, jamais une note d'échec.
3. **Le re-test 8 semaines (RCI L7)** — ligne 274 : « re-test programmé à 8 semaines » ; ligne 263 (L7) verbatim : « RCI longitudinal (Jacobson & Truax) : SE_diff = √2 × SEM ≈ 0,356 · \|Δ\| ≥ 0,58 = FIABLE · 0,41-0,58 = SUGGESTION · < 0,41 = BRUIT · + signification clinique si seuil traversé ». Le delta se calcule sur les **agrégats contresignés** (niveau détresse Q1, niveau charge Q2 — mêmes définitions que Q4-A1, bornes 2,50/3,50) : Δ = re-test − base, **jamais l'inverse** (asymétrie temporelle — homologue du anti-inversion Q4). Signification clinique = traversée des bornes A1 (2,50/3,50) — une mesure garde un seul rôle (les bornes restent les bornes de Q4).

**Asymétrie temporelle (D-CONFIRMATION Q5)** : la base est TOUJOURS le score contresigné d'origine, le re-test TOUJOURS le score à 8 semaines ; un delta inversé est une inversion de rive temporelle — éliminatoire.

## 9. Arbitrages ouverts (A1-A5) — à trancher avant verrouillage

> Le pont recommande sans trancher. Chaque option est ancrée sur une source ; aucune option rejetée ne crée de règle nouvelle.

- **A1 — Mécanique du check-in quotidien.** (a) *RECOMMANDÉ* : check-in binaire pur (le pas a-t-il été tenté aujourd'hui ? oui/non) — fidèle à « tracking d'engagement » (ligne 427) : l'engagement est attesté par la tentative, pas par une note quotidienne ; zéro échelle inventée. (b) binaire + ressenti 1-5/jour — matière qualitative, mais échelle non sourcée dans le programme (invention). (c) re-mesure quotidienne des faces Q1/Q2 — fidèle aux mesures mais intenable 14 jours (abandon massif garanti) et confondrait le suivi avec la re-mesure (le RCI à 8 semaines est le changement, pas le journal).
- **A2 — Source du pas.** (a) champ libre seul — la machine ne suggère rien (anti-fabrication maximal) mais laisse le couple sans appui, contraire à §5.4 « CE QUE TU PEUX CHANGER (3 paliers) » (ligne 210) qui FIXE des suggestions. (b) *RECOMMANDÉ* : banque de pas par palier 🟢🟠 ancrée sur les modules EXISTANTS (« plan des jours durs », « rituels de deux adultes », « revue mensuelle » — ligne 133) + forces Q3 (F-S1 à F-S6) ; le couple choisit dans la banque ou écrit le sien (champ libre préservé) — suggestions sans prescription, contenu existant sans invention. (c) pas prescrit automatiquement — rejeté (anti-fabrication §5.5, le choix reste au couple).
- **A3 — Table palier ← configuration Q4.** (a) *RECOMMANDÉ* : palier = max(niveau détresse, niveau charge) — CALME → 🟢 ; VEILLE, COURANT FORT, DEUX COURANTS → 🟠 ; PORTE SEULE, RIVE QUI CÈDE, TEMPÊTE, TEMPÊTE ET DIGUE, DÉBORDEMENT → 🔴 (+ note « vérifier le masquage » héritée Q4 sur PORTE SEULE) ; override crise → 🔴 orientation sans pas. Justification : mécanique pure (une règle, zéro exception), fidèle à §5.4 (« élevée/signal → orientation ») et à la clinique Zarit (charge Élevée = orientation de l'aidant lui-même). (b) variante nuancée : TEMPÊTE ET DIGUE → 🟠 (« le duo tient sous tension » — lecture Q4) — plus doux mais introduit une exception nommée dans la règle.
- **A4 — Périmètre du RCI à 8 semaines.** (a) *RECOMMANDÉ* : delta sur les DEUX agrégats (détresse Q1 + charge Q2), classification L7 verbatim (FIABLE ≥ 0,58 · SUGGESTION 0,41-0,58 · BRUIT < 0,41), signification clinique = traversée des bornes A1 (2,50/3,50). Justification : les deux rives sont les sorties contresignées pertinentes ; les bornes Q4 servent de seuils cliniques (une mesure, un rôle). (b) re-test de la configuration Q4 seulement (croisement re-calculé) — moins informatif, la config découle de (a) de toute façon. (c) hors périmètre — contraire à la ligne 274 (« re-test programmé à 8 semaines »).
- **A5 — C6 anti-fabrication de Q5.** (a) *RECOMMANDÉ* : C6 = « 0 sanction produite / 0 verdict de rémission » — le suivi célèbre l'engagement (≥ 9/14), relance chaleureuse sans libellé d'échec sinon ; BRUIT jamais converti en « pas de changement » ; FIABLE jamais converti en « guéri » (rémission = verdict clinique réservé au 🔴 professionnel). Justification : transposition directe de « jamais de sanction » (ligne 298) et de l'anti-surinterprétation L4. (b) C6 maintenu « 0 pas produit » — intenable : Q5 EST la quête du pas.

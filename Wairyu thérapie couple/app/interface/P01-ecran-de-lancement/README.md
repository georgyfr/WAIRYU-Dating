# P01 · Écran de lancement — Phase 0 (Arrivée)

**Fichiers** : `P01-ecran-de-lancement.html` (maquette interactive), `.png` / `@2x.png` (rendus). La maquette HTML inclut un panneau latéral rappelant les spécifications du document source pour vérification croisée.

## Rôle
Première rencontre avec l'application. Ce n'est pas un écran commercial : c'est une porte d'entrée calme, dans l'esprit « une app de paix, pas de conversion ».

## Contenu (fidèle à `01-pages-interface.md`)
- **Logo animé** : les deux visages se rapprochent, le cœur se forme entre eux, puis les 3 points (bleu, bleu clair, corail) apparaissent.
- Nom **« Wairyu »** + accroche exacte : *« Deux rives. Un courant. Un cœur à reconstruire. »*
- Eau qui ondule en bas d'écran (3 couches de vagues SVG, animation lente).

## Interaction
- **« Commencer mon voyage »** — bouton primaire turquoise `#6DD5C0` sur fond nuit `#1A2332`.
- **« J'ai déjà un compte »** — lien secondaire discret.

## Design & palette
| Élément | Valeur |
|---|---|
| Fond | nuit `#1A2332` |
| Primaire / courant | turquoise `#6DD5C0` |
| Texte | brume `#E6F7FF` |
| Accent attention | corail `#FF6B6B` (jamais en alerte agressive) |
| Typographie | douce, arrondie, grande lisibilité |

## Justifications UX / thérapeutiques
- **Zéro urgence** : aucun compte à rebours, aucune preuve sociale agressive, aucun « X personnes vous attendent ». L'anxiété relationnelle ne doit pas être exploitée dès le seuil.
- **Le logo comme promesse narrative** : l'animation des deux visages → cœur encode en 4 secondes la thèse du programme (deux rives individuelles, un lien à reconstruire).
- **L'eau = registre émotionnel** : introduire l'ondulation dès le premier écran installe la métaphore du fleuve qui structurera toute l'app (P05).
- **Enchaînement logique** : P01 → P02 (Création du duo, « chacun répond seul ») → P03 (Consentement éclairé) → P04 (RIO d'entrée) → P05 (Carte du fleuve).
